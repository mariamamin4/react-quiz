# React Quiz App

A simple quiz application built with React as part of my learning journey.

## About the Project

This project was developed for educational purposes while following **Jonas Schmedtmann's React course**.

The main goal was to practice React concepts and understand how to build an interactive application using React.

This is **not an entirely original project built independently from scratch**. I followed the course lessons and worked along with the instructor, making some modifications and additions for practice.

## Features

- Multiple-choice quiz questions.
- Different difficulty levels: Easy, Medium, and Hard.
- Previous and Next question navigation.
- Keeps selected answers when navigating between questions.
- Tracks the score and displays the final result.
- Timer for the quiz.
- High score tracking during the current session.

## Technologies Used

- React
- JavaScript
- CSS
- JSON Server

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/mariamamin4/react-quiz.git
   ```

2. Navigate to the project folder:

   ```bash
   cd react-quiz
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start JSON Server in a terminal:

   ```bash
   npx json-server db.json --port 8000
   ```

5. Start the React application in another terminal:

   ```bash
   npm run dev
   ```

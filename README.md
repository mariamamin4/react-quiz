# React Quiz App

A simple quiz application built while learning React with **Jonas Schmedtmann's React course**.

### Technologies

- React
- JavaScript
- CSS
- JSON Server

### Additional Features

I added two features for practice:

- Difficulty levels (Easy, Medium, Hard).
- Previous and Next question navigation with saved answers.

This is an educational project. I followed Jonas Schmedtmann's course and added the features mentioned above as part of my learning journey.
